## 🎯 项目说明

这是智能手表语音对话项目的**手机测试版本**，用于在正式移植到手表前验证所有功能。

### 核心功能
- 🎤 **语音对话** - 阿里云ASR + 扣子AI + 阿里云TTS
- 💰 **加密货币实时数据** - 轮播展示BTC/ETH/BCH等行情
- 🤖 **中本聪AI** - 专业的加密货币分析智能体
- 📱 **手机优化界面** - 适配手机屏幕

## 🚀 快速开始

### 前置要求

1. **安装HBuilderX**（已安装）
2. **启动本地服务器**（必需）
   ```powershell
   cd ..\server-deploy
   .\启动本地服务器.ps1
   ```
3. **确认服务器状态**
   - 看到"服务器运行在 http://192.168.40.1:8080"
   - 看到"阿里云Token获取成功"

### 浏览器测试（推荐第一步）

1. 打开HBuilderX
2. 文件 → 打开目录 → 选择 `CryptoPhone`
3. 运行 → 运行到浏览器 → Chrome
4. 允许麦克风权限
5. 点击"按住说话"进行测试

**浏览器测试优势：**
- 可以看到完整的控制台日志
- 调试更方便
- 无需编译打包

### 手机真机测试

1. **手机准备**
   - 开启USB调试模式
   - USB连接电脑
   - 确保手机和电脑在同一WiFi

2. **运行到手机**
   - 在HBuilderX中：运行 → 运行到手机或模拟器 → Android App基座
   - 选择你的手机设备
   - 等待编译安装（首次较慢）

3. **授权权限**
   - 应用启动后会请求麦克风权限
   - 点击"允许"

## 📱 使用说明

### 语音对话流程

1. **按住麦克风按钮** 🎤
   - 状态显示"录音中"
   - 按钮变红色

2. **松开按钮**
   - 状态显示"识别中"
   - 你说的话会显示在聊天界面

3. **AI思考**
   - 状态显示"AI思考中"
   - 等待AI回复

4. **语音播放**
   - 状态显示"播放中"
   - AI的回答会语音播报并显示在界面

5. **完成**
   - 状态回到"就绪"
   - 可以继续对话

### 加密货币数据

- 顶部轮播卡片自动刷新（30秒一次）
- 左右滑动查看不同货币
- 显示当前价格和涨跌幅

## 🐛 故障排查

### 问题1：无法连接服务器

**症状：** 应用启动后一直显示加载中

**解决方法：**
1. 检查服务器是否正在运行
2. 在手机浏览器访问 `http://192.168.40.1:8080/api/aliyun/config`
3. 如果无法访问，检查：
   - 手机和电脑是否在同一WiFi
   - 防火墙是否阻止（运行 `..\server-deploy\配置防火墙.ps1`）
   - IP地址是否正确

### 问题2：麦克风权限被拒绝

**症状：** 点击按钮提示"请允许麦克风权限"

**解决方法：**
- 手机设置 → 应用管理 → CryptoWatch-Mobile → 权限 → 麦克风 → 允许

### 问题3：AI回复为空或乱码

**症状：** ASR识别成功，但AI回复显示"抱歉，我没有理解你的问题"

**解决方法：**
1. 查看HBuilderX控制台日志
2. 搜索 `[ParseCoze]` 相关日志
3. 检查是否成功解析SSE响应
4. 如果看到解析错误，可能是网络问题，重试即可

**已修复：** 本版本已参考 `voice_chat_complete.html` 修复了SSE解析逻辑

### 问题4：TTS播放失败

**症状：** AI回复显示了，但没有语音

**解决方法：**
1. 检查手机音量
2. 检查阿里云Token是否过期（重启服务器重新获取）
3. 查看日志中的TTS相关错误

### 问题5：加密货币数据不显示

**症状：** 顶部轮播区域空白

**解决方法：**
- 这是正常的，加密货币API需要代理
- 目前会自动使用模拟数据
- 不影响语音对话功能

## 🆘 常见问题

**Q: 录音没有反应？**  
A: 检查manifest.json中的RECORD_AUDIO权限，确保已授权

**Q: 网络请求失败？**  
A: 检查服务器是否运行，config.js中的地址是否正确

**Q: 触摸按钮没反应？**  
A: 手表可能需要更大的按钮，修改.record-button的尺寸

**Q: 语音识别不准确？**  
A: 检查录音质量，确保环境安静，说话清晰
