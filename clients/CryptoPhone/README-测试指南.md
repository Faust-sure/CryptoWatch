## 🐛 调试技巧

### 查看日志
在HBuilderX中：
1. 控制台面板会显示所有console.log
2. 查找带有 `[Main]`, `[Voice API]`, `[AI API]`, `[Crypto API]` 的日志
3. 红色错误特别关注

### 常见问题排查
| 问题 | 排查方法 |
|------|---------|
| 加密货币不显示 | 查看`[Crypto API]`和`[Main]`日志，确认数据加载流程 |
| 麦克风无权限 | 检查是否弹出权限申请，是否在系统设置中允许 |
| 录音无响应 | 查看`[Voice API]`日志，确认ASR请求是否成功 |
| AI不回答 | 查看`[AI API]`日志，确认project_id和session_id |
| 无法播放语音 | 查看TTS URL生成是否正确，网络是否连通 |

### 网络检查
```javascript
// 在控制台运行，测试服务器连接
uni.request({
  url: 'http://47.97.121.208:8080/',
  success: (res) => console.log('服务器连通:', res),
  fail: (err) => console.error('服务器不通:', err)
})
```
