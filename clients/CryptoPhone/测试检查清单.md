## 2️⃣ 加密货币数据测试

### 数据显示
- [ ] 顶部区域显示加密货币轮播
- [ ] 至少显示5种货币（BTC, ETH, USDT, BNB, XRP）
- [ ] 每个货币卡片显示：
  - [ ] 货币名称（如 Bitcoin）
  - [ ] 货币符号（如 BTC）
  - [ ] 当前价格
  - [ ] 涨跌幅（带颜色）

### 价格真实性
- [ ] BTC价格在 $90,000 - $100,000 范围
- [ ] ETH价格在 $3,000 - $3,500 范围
- [ ] USDT价格接近 $1.00
- [ ] BNB价格在 $600 - $700 范围
- [ ] XRP价格在 $2.00 - $3.00 范围

### 交互功能
- [ ] 可以左右滑动切换货币
- [ ] 滑动流畅，无卡顿
- [ ] 等待30秒后数据自动刷新
- [ ] 刷新后价格有小幅波动

### 控制台日志（重要！）
打开HBuilderX控制台，检查：
- [ ] 看到 `[Crypto API]` 相关日志
- [ ] 看到 `[Main] 开始加载加密货币数据...`
- [ ] 看到 `[Main] 加密货币数据加载成功: 5 条`
- [ ] 确认数据来源（`来源:mock` 或 `来源:server`）

**如果看到 mock：** 正常，说明服务器未返回数据，使用了Fallback  
**如果看到 server：** 很好，说明服务器数据正常
