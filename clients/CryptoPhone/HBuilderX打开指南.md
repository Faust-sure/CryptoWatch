# HBuilderX 打开和测试 CryptoWatch-Mobile

## 步骤1：在HBuilderX中打开项目

1. **关闭当前的 Cryptophone 项目**
2. **文件** → **打开目录**
3. 浏览到：`C:\Users\25841\Desktop\watch\CryptoWatch-Mobile`
4. 点击"选择文件夹"

## 步骤2：USB真机调试（推荐）

### 准备工作
1. **手机设置**：
   - 开启"开发者选项"
   - 开启"USB调试"
   - 开启"安装未知来源应用"（部分手机需要）
   
2. **连接手机**：
   - USB线连接手机到电脑
   - 手机弹出USB调试授权，点击"允许"

### 开始调试
1. 在HBuilderX中点击：**运行** → **运行到手机或模拟器** → **运行到Android App基座**
2. 等待HBuilderX识别到你的手机（会显示手机型号）
3. 点击你的手机设备
4. 等待编译和安装（第一次会下载基座，需要几分钟）
5. 安装完成后，应用会自动启动

### 实时调试优势
- 修改代码后，点击"运行"即可立即看到效果
- 无需重新打包
- 可以在HBuilderX控制台查看日志
- 非常适合快速迭代测试

## 步骤3：查看控制台日志

1. HBuilderX底部有"控制台"面板
2. 选择对应的设备
3. 查看所有console.log输出
4. 重点关注：
   - `[Main]` - 主流程
   - `[Crypto API]` - 加密货币数据
   - `[Voice API]` - 语音功能
   - `[AI API]` - AI对话

## 常见问题

### Q1: HBuilderX找不到设备？
- 检查USB调试是否开启
- 更换USB线或USB口
- 重启手机的USB调试
- 安装手机驱动（小米、华为等需要）

### Q2: 安装失败？
- 检查手机是否允许USB安装应用
- 卸载旧版本（如果有）
- 检查手机存储空间

### Q3: 应用闪退？
- 查看控制台错误日志
- 检查权限是否授予
- 重新安装应用

### Q4: 看不到日志？
- 确保选择了正确的设备标签
- 点击控制台的"刷新"按钮
- 重启应用
