### 4. 常见问题

**Q1: 看不到加密货币数据，显示"加载中..."**
- 打开F12控制台，查看是否有错误
- 如果看到Mock数据，说明CoinGecko/CMC API超时，这是正常的
- Mock数据也是动态的，会每30秒更新

**Q2: 麦克风无法授权**
- Chrome必须在HTTPS或localhost才能访问麦克风
- 确认地址栏显示的是 `localhost:xxxx`
- 如果还是不行，尝试Firefox浏览器

**Q3: 点击录音按钮没反应**
- 打开F12控制台，查看是否有错误信息
- 检查服务器是否正常：在新标签页访问 `http://47.97.121.208:8080`
- 应该看到 `CryptoWatch Server Running`

**Q4: 语音识别失败或AI不回复**
- 查看F12控制台的错误信息
- 可能的原因：
  - 阿里云Token过期（服务器会自动生成新Token）
  - 扣子AI调用失败（检查网络）
  - 录音文件格式问题（uni-app录音可能与浏览器不兼容）

## 📋 第二步：手表真机调试

### 前置准备
1. **手表设置**
   - 进入设置 → 关于手表
   - 连续点击版本号7次，开启开发者模式
   - 开发者选项 → 开启USB调试
   - 开发者选项 → 开启USB安装（如果有）

2. **电脑设置**
   - 通过USB数据线连接手表到电脑
   - 手表上会弹出"允许USB调试"，点击允许
   - 确认Windows能识别设备（设备管理器中能看到Android设备）

### 运行到手表

#### 方式A：真机调试（推荐）
```
1. HBuilderX → 运行 → 运行到手机或模拟器
2. 如果能看到你的手表设备，点击选择
3. 等待APP安装并启动（首次较慢，约1-2分钟）
4. 手表上会自动打开APP
```

**优点：**
- 修改代码后可以热更新（无需重新打包）
- 可以查看实时日志
- 适合快速调试

**缺点：**
- 需要保持USB连接
- 性能可能不如正式版

#### 方式B：云打包（正式测试）
```
1. HBuilderX → 发行 → 原生App-云打包
2. 选择Android平台
3. 填写应用信息：
   - 应用名称：CryptoWatch
   - 应用版本号：1.0.0
   - 包名：com.sifuture.cryptowatch
4. 点击打包
5. 等待打包完成（5-10分钟）
6. 下载APK文件
7. 通过ADB安装：adb install CryptoWatch.apk
   或者拷贝到手表存储后手动安装
```

**优点：**
- 真实的APP体验
- 性能最佳
- 可以脱离电脑运行

**缺点：**
- 每次修改都要重新打包（费时）
- 不适合快速试错

- [ ] 手表能否访问服务器
