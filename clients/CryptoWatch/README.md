# CryptoWatch uni-app项目说明

## 📱 项目概述

这是一个智能手表语音对话应用，集成了：
- 🎤 **语音对话** - 阿里云ASR + 扣子AI + 阿里云TTS
- 💰 **加密货币实时数据** - 轮播展示比特币等行情
- 🤖 **中本聪AI** - 专业的加密货币分析智能体

## 🎯 主要功能

### 1. 语音对话流程

1. **用户按住录音按钮** → 开始录音
2. **松开按钮** → 停止录音
3. **自动流程：**
   - 上传音频 → 阿里云ASR识别
   - 识别结果 → 扣子AI处理
   - AI回复 → 阿里云TTS合成
   - 播放语音 + 显示文字

### 2. 加密货币展示

- 自动轮播5种加密货币
- 显示实时价格、涨跌幅
- 30秒自动刷新
- 左右滑动查看

### 3. 状态指示

- **就绪** - 灰色背景
- **正在录音** - 红色闪烁
- **识别中/思考中** - 蓝色
- **播放中** - 绿色

## 🔧 调试技巧

### 1. 查看控制台日志

在HBuilderX底部的"控制台"面板查看：
- 录音状态
- API调用结果
- 错误信息

### 2. 网络请求调试

如果手表无法连接服务器：
1. 确保手表和电脑在同一WiFi
2. 检查电脑IP地址（ipconfig）
3. 修改config.js中的LOCAL地址为电脑IP

### 3. 手表触摸问题

如果按钮触摸不灵敏：
1. 增大按钮尺寸（index.vue中的.record-button）
2. 调整touch事件灵敏度
3. 添加触觉反馈

## 🆘 常见问题

**Q: 录音没有反应？**  
A: 检查manifest.json中的RECORD_AUDIO权限，确保已授权

**Q: 网络请求失败？**  
A: 检查服务器是否运行，config.js中的地址是否正确

**Q: 触摸按钮没反应？**  
A: 手表可能需要更大的按钮，修改.record-button的尺寸

**Q: 语音识别不准确？**  
A: 检查录音质量，确保环境安静，说话清晰
