## ✅ 已修复的问题

### 1. 麦克风权限申请（已修复）

**问题现象：**
- 在手机测试时没有看到权限申请弹窗
- 麦克风无法打开
- 报错：gateway: parameter invalid: appkey not set

**根本原因：**
- uni-app没有主动申请录音权限
- 需要使用 `uni.authorize()` API

**修复方案：**
在 [CryptoWatch/pages/index/index.vue](CryptoWatch/pages/index/index.vue#L97-L118) 添加了：
```javascript
// 请求录音权限
requestRecordPermission() {
    return new Promise((resolve) => {
        uni.authorize({
            scope: 'scope.record',
            success: () => {
                console.log('录音权限已授予')
                resolve(true)
            },
            fail: () => {
                console.log('录音权限被拒绝，引导用户设置')
                uni.showModal({
                    title: '需要录音权限',
                    content: '请在设置中开启录音权限，以使用语音对话功能',
                    success: (res) => {
                        if (res.confirm) {
                            uni.openSetting()
                        }
                    }
                })
                resolve(false)
            }
        })
    })
}
```

**在init()中调用：**
```javascript
async init() {
    // ...
    // 请求录音权限
    await this.requestRecordPermission()
    // ...
}
```

### 2. appkey参数错误（已修复）

**问题现象：**
- 报错：gateway: parameter invalid: appkey not set

**根本原因：**
- 服务器返回的字段名是 `appKey`（驼峰命名）
- 但代码中使用的是 `config.appKey`
- 可能存在大小写不匹配

**修复方案：**
在 [CryptoWatch/api/voice.js](CryptoWatch/api/voice.js#L44-L49) 兼容两种格式：
```javascript
const formData = {
    appkey: config.appKey || config.appkey,  // 兼容两种格式
    token: config.token
};
console.log('ASR请求参数:', formData);  // 添加日志
```

## ⚠️ APK安装问题（需进一步调查）

### 问题现象
- 使用QQ浏览器下载APK
- 安装进行到一半后终止
- 具体原因未知

### 可能原因

**1. 签名问题**
- 云打包使用的证书不被手表系统信任
- 建议：使用DCloud公用证书重新打包

**2. 应用权限过多**
- manifest.json配置的权限过多导致系统拒绝
- 当前配置的权限：RECORD_AUDIO, INTERNET, 等

**3. 手表系统限制**
- 某些手表系统对第三方应用安装有限制
- 需要在设置中开启"允许安装未知应用"

**4. APK损坏**
- 下载过程中文件损坏
- 建议：检查APK文件完整性

**5. 安装空间不足**
- 手表存储空间不足
- 建议：清理手表存储空间

### 排查步骤

**步骤1：检查安装来源设置**
```
手表设置 → 安全 → 未知来源 → 允许
或
手表设置 → 应用管理 → QQ浏览器 → 允许安装未知应用
```

**步骤2：使用adb查看详细错误**
```bash
# 连接手表
adb connect <手表IP>

# 查看安装日志
adb logcat | grep -i "packageinstaller\|error"

# 手动安装APK查看详细错误
adb install -r CryptoWatch.apk
```

**步骤3：尝试不同的安装方式**
```
方式A：使用文件管理器直接安装
方式B：使用adb install
方式C：使用其他浏览器下载（Chrome、UC等）
方式D：通过电脑传输到手表SD卡后安装
```

**步骤4：检查APK信息**
```bash
# Windows PowerShell
# 需要安装Android SDK
aapt dump badging CryptoWatch.apk

# 查看APK大小（如果过大可能是问题）
Get-Item CryptoWatch.apk | Select-Object Name, Length
```

**步骤5：简化权限重新打包**

临时修改 `manifest.json`，只保留必要权限：
```json
"android": {
    "permissions": [
        "RECORD_AUDIO",
        "INTERNET"
    ]
}
```

**步骤6：使用DCloud公用证书**

HBuilderX云打包时选择：
- 证书：使用DCloud公用证书（而不是自有证书）
- 这样可以避免签名问题
