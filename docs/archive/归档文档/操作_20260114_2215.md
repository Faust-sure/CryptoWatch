## 🚨 重要注意事项与经验教训

### 关键技术要点
1. **Token有效期：** 阿里云Token有效期24小时，过期自动重新生成
2. **ASR参数传递：** 必须使用URL参数，不能用HTTP header
3. **Python命令：** Windows环境使用`python`，Linux使用`python3`
4. **SSE流式响应：** 需要逐行解析`data: `开头的内容
5. **跨域问题：** 服务器需要正确设置CORS头

### 服务器操作原则
1. **操作前先检查状态** - 避免盲目修改配置
2. **保持服务运行** - 修改配置前备份，修改后重启验证
3. **查看日志定位问题** - nginx错误日志、systemd日志
4. **测试API再测网页** - 先确保后端正常，再排查前端问题

### 调试技巧
1. **分步测试：** 先测TTS → 再测ASR → 最后测完整流程
2. **使用HTML验证：** 功能不确定时先用HTML测试页验证
3. **查看控制台：** 浏览器开发者工具查看网络请求和错误
4. **对比参考实现：** 不确定时参考voice_chat_complete.html
