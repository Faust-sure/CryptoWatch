## 🖥️ server-deploy/（服务器端）

**用途：** Node.js后端服务，提供API代理

```
server-deploy/
├── server.js                    # Node.js主服务器（当前版本）
├── server-fixed.js              # 备份版本
├── get_aliyun_token.py          # 阿里云Token生成脚本
├── package.json                 # Node.js依赖配置
├── cryptowatch.service          # systemd服务配置
├── nginx-cryptowatch.conf       # Nginx配置（可选）
└── README.md                    # 部署说明
```

**API端点：**
- `GET /` - 健康检查
- `GET /api/aliyun/config` - 阿里云配置（Token/AppKey）
- `POST /api/aliyun/asr` - 语音识别
- `GET /api/aliyun/tts` - 语音合成
- `POST /api/coze` - 扣子AI对话
- `GET /api/crypto/latest` - 加密货币数据
