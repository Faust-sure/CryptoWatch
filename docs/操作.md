### 当前HBuilder方案
```
HBuilder uni-app (Vue) 
  ↓ 编译
Android APK (云打包/本地打包)
  ↓ 
❌ 手表安装失败（权限/签名问题）
```

### 新方案：Android Studio原生
```
Android Studio原生项目
  ├── WebView加载前端页面（复用现有Vue代码）
  ├── 原生权限管理（麦克风、网络）
  └── 原生API调用（录音、播放）
  ↓
真正的APK（完整签名控制）
  ↓
✅ 手表兼容性更好
```

```
Node.js (server.js) 监听 :8080
  ├── /api/aliyun/asr → 阿里云ASR（语音识别）
  ├── /api/aliyun/tts → 阿里云TTS（语音合成）
  ├── /api/ai/chat → 扣子AI（SSE流式回复）
  └── /api/crypto/prices → 加密货币价格
```

## 🔧 关键技术要点

### H5环境兼容性修复

**问题：** uni-app的某些API在浏览器环境不可用
- `uni.authorize` → 浏览器原生权限API
- `uni.getRecorderManager` → MediaRecorder
- 文件上传 → fetch + FormData + Blob

**解决方案：** 使用条件编译
```javascript
// #ifdef H5
// H5环境代码
// #endif

// #ifndef H5
// 非H5环境代码（App）
// #endif
```

### 扣子AI SSE格式解析

**正确格式：**
```javascript
if (line.startsWith('data: ')) {
    const jsonStr = line.substring(6)  // 去掉"data: "
    const data = JSON.parse(jsonStr)
    if (data.type === 'answer' && data.content?.answer) {
        fullAnswer += data.content.answer  // 注意是content.answer
    }
}
```
